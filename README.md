# Anjalis-race
Formula 1 Race Intelligence Dashboard using Tableau for race performance, driver analysis, team performance, pit stop comparison, and circuit analysis.
🏎️ Formula 1 Race Intelligence Dashboard

📌 Project Overview

The Formula 1 Race Intelligence Dashboard is a data visualization project developed using Tableau. It provides insights into race performance, driver performance, team performance, pit stop comparisons, and circuit analysis.

🎯 Project Objectives

* Analyze Formula 1 race performance.
* Compare driver performance.
* Evaluate team performance.
* Analyze pit stop data.
* Explore circuit-related insights through interactive visualizations.

🛠️ Tools Used

* Tableau Public
* Microsoft Excel
* GitHub
